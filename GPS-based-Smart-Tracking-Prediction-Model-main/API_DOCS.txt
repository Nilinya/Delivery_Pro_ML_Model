"""
API DOCUMENTATION
=================

BASE URL: http://localhost:5000


ENDPOINTS
=========

1. HOME PAGE
   GET /
   Description: Serve the UI for testing predictions
   Response: HTML page
   Example: http://localhost:5000/


2. HEALTH CHECK
   GET /api/health
   Description: Check if API and model are loaded
   Response: 
   {
       "status": "healthy",
       "model_loaded": true
   }


3. SINGLE PREDICTION
   POST /api/predict
   Description: Predict delivery time for a single order
   
   Request Body (JSON):
   {
       "Delivery_person_Age": 37,
       "Delivery_person_Ratings": 4.9,
       "Restaurant_latitude": 22.745,
       "Restaurant_longitude": 75.892,
       "Delivery_location_latitude": 22.765,
       "Delivery_location_longitude": 75.912,
       "Weatherconditions": "conditions Sunny",
       "Road_traffic_density": "High",
       "Vehicle_condition": 2,
       "Type_of_order": "Snack",
       "Type_of_vehicle": "motorcycle",
       "multiple_deliveries": 0,
       "Festival": "No",
       "City": "Urban",
       "Order_Date": "19-03-2022",
       "Time_Orderd": "113000",
       "Time_Order_picked": "114500"
   }
   
   Response:
   {
       "success": true,
       "predicted_time_minutes": 25.5,
       "message": "Predicted delivery time: 25.5 minutes"
   }


4. BATCH PREDICTION
   POST /api/predict-batch
   Description: Predict delivery times for multiple orders
   
   Request Body (JSON Array):
   [
       {
           "Delivery_person_Age": 37,
           "Delivery_person_Ratings": 4.9,
           ...
       },
       {
           "Delivery_person_Age": 28,
           "Delivery_person_Ratings": 4.7,
           ...
       }
   ]
   
   Response:
   {
       "success": true,
       "predictions": [25.5, 22.1],
       "count": 2,
       "message": "Generated 2 predictions"
   }


FIELD REQUIREMENTS
==================

Required Fields:
- Delivery_person_Age (int, 18-100)
- Delivery_person_Ratings (float, 1.0-5.0)
- Restaurant_latitude (float)
- Restaurant_longitude (float)
- Delivery_location_latitude (float)
- Delivery_location_longitude (float)
- Weatherconditions (str)
- Road_traffic_density (str)
- Vehicle_condition (int, 1-3)
- Type_of_order (str)
- Type_of_vehicle (str)
- multiple_deliveries (int, 0-5)
- Festival (str: "Yes" or "No")
- City (str)
- Order_Date (str, format: DD-MM-YYYY)
- Time_Orderd (str, format: HHMMSS)
- Time_Order_picked (str, format: HHMMSS)


EXAMPLE CURL COMMANDS
=====================

1. Health Check:
   curl http://localhost:5000/api/health

2. Single Prediction:
   curl -X POST http://localhost:5000/api/predict \\
     -H "Content-Type: application/json" \\
     -d '{
       "Delivery_person_Age": 37,
       "Delivery_person_Ratings": 4.9,
       "Restaurant_latitude": 22.745,
       "Restaurant_longitude": 75.892,
       "Delivery_location_latitude": 22.765,
       "Delivery_location_longitude": 75.912,
       "Weatherconditions": "conditions Sunny",
       "Road_traffic_density": "High",
       "Vehicle_condition": 2,
       "Type_of_order": "Snack",
       "Type_of_vehicle": "motorcycle",
       "multiple_deliveries": 0,
       "Festival": "No",
       "City": "Urban",
       "Order_Date": "19-03-2022",
       "Time_Orderd": "113000",
       "Time_Order_picked": "114500"
     }'

3. Batch Prediction:
   curl -X POST http://localhost:5000/api/predict-batch \\
     -H "Content-Type: application/json" \\
     -d '[
       {"Delivery_person_Age": 37, ...},
       {"Delivery_person_Age": 28, ...}
     ]'


ERROR RESPONSES
===============

400 Bad Request:
{
    "success": false,
    "message": "Error description"
}

404 Not Found:
{
    "success": false,
    "message": "Endpoint not found"
}

500 Internal Server Error:
{
    "success": false,
    "message": "Internal server error"
}


DEPLOYMENT
==========

Development:
  python app.py

Production with Gunicorn:
  gunicorn -w 4 -b 0.0.0.0:5000 wsgi:app

Docker:
  docker build -t delivery-predictor .
  docker run -p 5000:5000 delivery-predictor

Docker Compose:
  docker-compose up
"""
